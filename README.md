# SQL Murder Mystery Investigation

## Project Overview
This project involved investigating a murder mystery using SQL. The goal was to explore a database, examine crime-related records, follow investigative leads, and use the available evidence to solve the case.

## Objectives
- Explore a relational database using SQL.
- Retrieve relevant information using SQL queries.
- Filter records and investigate potential leads.
- Apply logical reasoning to analyse evidence.
- Draw conclusions from query results.

## Tools Used
- SQL
- Relational databases
- SQL queries for data exploration and investigation

## Methodology
1. Explored the available database records.
2. Queried relevant tables to gather information.
3. Investigated leads using SQL queries.
4. Analysed query results to narrow down potential suspects.
5. Used the evidence to reach a conclusion.

## Skills Demonstrated
- SQL querying
- Data exploration and filtering
- Logical reasoning
- Problem-solving
- Data interpretation

## Project File
- sql-murder-mystery.sql — Contains the SQL queries and investigative notes used in the project.

## Key Takeaway
This project strengthened my ability to investigate data systematically, write SQL queries, interpret results, and solve problems using evidence.
